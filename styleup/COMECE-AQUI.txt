StyleUp — leia isto primeiro
============================

O projeto roda SEM configurar nada: sem conta no Supabase, sem chave de API.
A API sobe em modo demonstração, com um guarda-roupa de exemplo já carregado.

Precisa ter instalado: Python 3.11 ou mais novo, e Node 18 ou mais novo.


PASSO 1 — abra um terminal na pasta do projeto e rode a API
-----------------------------------------------------------
  cd backend
  python -m venv .venv
  .venv\Scripts\activate            (Windows)
  source .venv/bin/activate         (Linux ou Mac)
  pip install -r requirements.txt
  uvicorn app.main:app --reload --port 8000

Deixe esse terminal aberto.


PASSO 2 — abra um SEGUNDO terminal e rode o frontend
----------------------------------------------------
  cd frontend
  npm install
  npm run dev


PASSO 3 — abra no navegador
---------------------------
  http://localhost:5173

Escolha um compromisso e clique em "Recomendar".


Para rodar os testes (180 testes, cerca de 1 segundo):
  cd backend
  python -m pytest
